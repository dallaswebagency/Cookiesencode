# CookiesEncode website

Static HTML/CSS/JS build of cookiesencode.com (formerly Dallas Web Agency).

- `index.html`: homepage (Phase 2, awaiting approval)
- `assets/css/main.css`: design system tokens and components
- `assets/js/main.js`: header, mobile nav, scroll reveal
- `assets/img/`: logo (light and dark backgrounds), icon

Placeholders are marked with `PLACEHOLDER` comments in the HTML.
